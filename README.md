# Intelligent Solar PV–Battery Energy Management System for Peak Load Shaving

This project implements an Energy Management System (EMS) for coordinating solar photovoltaic (PV) generation, battery storage, and electrical loads to reduce grid power consumption during periods of high demand.

The project includes two simulation tracks:

- **Track A: MATLAB Scripts:** Performs energy-balance calculations, electrical modelling, and result generation.
- **Track B: Simulink Models:** Simulates the EMS using dynamic system models and generates figures from logged simulation signals.

## Project Structure

Keep the following files together in the same folder before running the simulations.

```text
Project/
├── params_ems.m
├── level1_energy_balance.m
├── level2_electrical.m
├── make_profiles.m
├── make_figures.m
├── profile_winter_typical.csv              # Optional real-data profile
├── profile_summer_typical.csv              # Optional real-data profile
├── profile_winter_realday.csv              # Optional real-data profile
├── profile_summer_realday.csv              # Optional real-data profile
├── EMSLEVEL1.slx
├── EMSLEVEL2.slx
├── results_level1/               # Generated by Track A
├── results_level2/               # Generated by Track A
├── figures_L1/                   # Generated by Track B
└── figures_L2/                   # Generated by Track B
```

*Note: The results and figures folders are generated when the corresponding scripts or commands are executed. They do not need to exist beforehand. Also these files are present in the "SimulationFiles and DataProfiles*

## Setup — One-Time Configuration

1. Place `params_ems.m`, `level1_energy_balance.m`, `level2_electrical.m`, `make_profiles.m`, `make_figures.m`, all four profile CSV files, and both Simulink models in a single folder.
2. Open MATLAB and set this folder as the **Current Folder**.
3. Ensure that all required files are available in the MATLAB working directory.

**Important:** Do not run `params_ems.m` independently. The other scripts and the Simulink models call it when required.

## Track A: MATLAB Scripts (Reference Calculations)

This track executes the MATLAB scripts to calculate system performance and export the results.

### Step 1: Run the Level 2 Electrical Model

Run the following script in MATLAB:

```matlab
level2_electrical
```

The script performs the electrical calculations and saves the generated figures and CSV files in:

```text
results_level2/
```

At the end of execution, MATLAB prints the calculated losses and power-factor fitting results in the Command Window.

The current fitted values are already included in Section 2 of `params_ems.m`. You only need to update these values if the electrical circuit changes and the fitting process needs to be repeated.

### Step 2: Select an Input Profile (Optional but Highly Recommended)

The model can use real world profile data or a synthetic daily profile (if we refrain from using real world data).
the reason it is highly recommended to use real world profile data, as the simulations demonstrate how the system behaves during a natural load changes of a residential house recorded at bareilly and mathura taken 
from the offical harvard database "https://dataverse.harvard.edu/citation?persistentId=doi:10.7910/DVN/GOCHJH" 
*Note: Claude was used to assist in screening and filtering invalid or unsuitable datasets obtained from this source before they were used in the project. This helped improve the quality and
consistency of the data used for model development and simulation. The data selection and processing were reviewed for suitability for the project's objectives.*

To use real data:

1. Select the desired profile CSV file.
2. Copy it into the project folder.
3. Rename the copy to `profile_day.csv`.

The original profile CSV files should be preserved.

If `profile_day.csv` is not present, the script uses the synthetic daily profile.

### Step 3: Run the Level 1 Energy-Balance Model

Run:

```matlab
level1_energy_balance
```

The script calculates the Level 1 energy balance and generates the corresponding outputs in:

```text
results_level1/
```

The output folder contains:

- Generated figures.
- `level1_results.csv`
- `level1_metrics.csv`

This completes the MATLAB script-based simulation workflow.

## Track B: Simulink Models

This track uses the Simulink models to simulate the EMS dynamically. Follow the steps in order, especially when changing the input profile.

### Step 1: Generate the Input Profiles

Open `make_profiles.m` in the MATLAB Editor.

Set the `profile_file` variable on line 17 to the desired profile file by default it should be set to "profile_day", then run:

```matlab
make_profiles
```

**Important:** Run `make_profiles.m` before every Level 1 simulation and whenever you switch to a different input profile. This ensures the simulation uses the intended profile.

### Step 2: Configure and Run EMSLEVEL1

Open:

```text
EMSLEVEL1.slx
```

In Simulink, navigate to **Model Properties → Callbacks**.

Ensure the following command is present in both `PostLoadFcn` and `InitFcn`:

```matlab
params_ems; Ts=5e-6; cap=p.invACDC(p.P_lim);
```

Next:

1. Press **Ctrl+D** to update the model and check for errors.
2. Set the simulation **Stop Time** to `86400` seconds.
3. Run the simulation.

After the simulation, execute the following commands in MATLAB:

```matlab
out = sim('EMSLEVEL1');

make_figures(out, 1, 'figures_L1', ...
    'Name of the dataprofile')
```
for example if the "profile_summmer_typical.csv" dataset is used then the command should look like

```matlab
out = sim('EMSLEVEL1');

make_figures(out, 1, 'figures_L1', ...
    'Summer Typical Data (CEEW)
```

The generated Level 1 figures are saved in:

```text
figures_L1/
```

### Step 3: Configure and Run EMSLEVEL2

Open:

```text
EMSLEVEL2.slx
```

Verify that the same callback command is present in both `PostLoadFcn` and `InitFcn`:

```matlab
params_ems; Ts=5e-6; cap=p.invACDC(p.P_lim);
```

Next:

1. Press **Ctrl+D** to update the model and check for errors.
2. Set the simulation **Stop Time** to `3` seconds.
3. Run the simulation.

After the simulation, execute:

```matlab
out2 = sim('EMSLEVEL2');

make_figures(out2, 2, 'figures_L2')
```

The generated Level 2 figures are saved in:

```text
figures_L2/
```

## Output Directories

The project generates two sets of output directories, depending on the simulation track.

| Directory | Generated by | Contents |
|---|---|---|
| `results_level1/` | `level1_energy_balance.m` | Level 1 figures, results CSV and metrics CSV |
| `results_level2/` | `level2_electrical.m` | Level 2 electrical figures and CSV files |
| `figures_L1/` | `make_figures` for Level 1 | Figures generated from logged Simulink signals |
| `figures_L2/` | `make_figures` for Level 2 | Figures generated from logged Simulink signals |

**Note:** The MATLAB script track creates the two `results_*` folders in the same project directory. The Simulink track creates the two `figures_*` folders when the corresponding `make_figures` commands execute. These are separate output sets.

## Important Notes

- Always set the project directory as the MATLAB Current Folder before running the scripts.
- Do not execute `params_ems.m` independently.
- Run `make_profiles.m` before each Level 1 Simulink run and whenever the selected profile changes.
- Ensure the required Simulink signals are logged before calling `make_figures`.
- Keep the original profile CSV files unchanged; use a renamed copy when selecting `profile_day.csv`.

## Troubleshooting

**MATLAB cannot find a script or file**

Check that the project folder is selected as the Current Folder and that all required files are present.

**The Simulink model reports undefined variables**

Verify the `PostLoadFcn` and `InitFcn` callbacks and ensure that the callback command is exactly as specified above.

**The wrong profile is being simulated**

Check the `profile_file` setting in `make_profiles.m` and regenerate the profiles before rerunning Level 1.
